# Sales Prediction Using Python

## 📌 Overview

This project focuses on predicting product sales based on advertising expenditure using Machine Learning in Python.

The model analyzes advertising spending on **TV, Radio, and Newspaper** to predict the expected sales.

## 🎯 Objective

The main objective of this project is to build a regression model that can predict sales based on different advertising investments.

## 📊 Dataset

The dataset contains 200 records with the following columns:

* **TV** – Advertising expenditure on TV
* **Radio** – Advertising expenditure on Radio
* **Newspaper** – Advertising expenditure on Newspaper
* **Sales** – Product sales (Target Variable)

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Joblib
* Jupyter Notebook

## 🤖 Machine Learning Model

**Random Forest Regressor**

This is a **Regression** problem because the target variable, Sales, is a continuous numerical value.

## 📈 Model Performance

The model achieved an **R² Score of 95.35%** on the test dataset.

Evaluation metrics used:

* MAE: **0.918**
* MSE: **1.437**
* RMSE: **1.199**
* R² Score: **0.9535**

## 🔮 Sample Prediction

For the following advertising expenditure:

* TV = 200
* Radio = 30
* Newspaper = 20

The model predicted:

**Sales = 18.459**

## 📂 Files

* `Sales_Prediction.ipynb` – Jupyter Notebook containing the complete analysis and model
* `sales_prediction_model.pkl` – Trained Random Forest Regression model
